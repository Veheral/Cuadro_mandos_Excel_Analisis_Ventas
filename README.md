## 📊 Cuadro de Mando de Análisis de Ventas

El objetivo principal es proporcionar una herramienta visual que permita comprender el comportamiento comercial, identificar tendencias y apoyar la toma de decisiones estratégicas.

Este proyecto desarrolla un **cuadro de mando interactivo** para analizar el rendimiento de ventas de una empresa de distribución alimentaria. A partir de un conjunto de datos realista con más de **1.200 registros de pedidos**, se construye un modelo de análisis que permite explorar:

- Ingresos  
- Cantidades vendidas  
- Categorías de producto  
- Desempeño por región  
- Actividad de vendedores  
- Clientes  
- Métodos de pago  

El objetivo es ofrecer una visión clara y accionable del negocio, facilitando la toma de decisiones comerciales mediante indicadores clave, segmentaciones dinámicas y visualizaciones intuitivas.

---

### 📁 El proyecto incluye:

1. **Limpieza y preparación del conjunto de datos**  
2. **Modelado de datos y creación de métricas**  
3. **Diseño de un tablero profesional orientado a negocio**  
4. **Análisis de patrones de venta y detección de oportunidades**

---

Este cuadro de mando  **transformr datos brutos en información estratégica**.
