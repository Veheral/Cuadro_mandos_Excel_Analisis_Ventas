Cuadro de Mando de Análisis de Ventas

Este proyecto desarrolla un cuadro de mando interactivo para analizar el rendimiento de ventas de una empresa de distribución alimentaria. A partir de un dataset realista con más de 1.200 registros de pedidos, se construye un modelo de análisis que permite explorar ingresos, cantidades vendidas, categorías de producto, desempeño por región, vendedores, clientes y métodos de pago.
El objetivo es ofrecer una visión clara y accionable del negocio, facilitando la toma de decisiones comerciales mediante indicadores clave, segmentaciones dinámicas y visualizaciones intuitivas.

El proyecto incluye:

Limpieza y preparación del dataset.

Modelado de datos y creación de métricas.

Diseño de un dashboard profesional orientado a negocio.

Análisis de patrones de venta y detección de oportunidades.

Este cuadro de mando forma parte de mi portfolio como analista de datos y demuestra mi capacidad para transformar datos brutos en información estratégica.
